Notes:
  • To render HTML instead of showing source, this page converts raw GitHub URLs to a renderable URL using raw.githack.com when possible or htmlpreview.github.io as a fallback.
  • These services are public third-party renderers. If you'd rather self-host, enable GitHub Pages for the repo and point links to the Pages URL instead.
  • Unauthenticated GitHub API requests are limited (60 requests/hour). Consider adding a static manifest (games.json) if you hit rate limits.
